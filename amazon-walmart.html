Amazon Ecosystem vs Walmart

แผนที่เครือข่าย API แสดงว่าใครเป็น “ศูนย์กลาง” ที่นักพัฒนาและพาร์ทเนอร์ทั่วโลกเลือกมาเชื่อมต่อ — ภาพเดียวที่อธิบายความต่างระหว่างบริษัทที่ขายสินค้า กับบริษัทที่เป็นเจ้าของระบบนิเวศ
แต่ละจุดคือ API หนึ่งตัว เส้นคือการที่แอปหรือบริการนำ API ไปใช้ร่วมกัน สีแทนกลุ่มการใช้งาน · คลิกภาพเพื่อขยาย

Amazon

  • API กระจายอยู่ใน 3 กลุ่มใหญ่: Social/web, E-commerce และ Cloud/big data
  • อยู่ใจกลางเครือข่าย เชื่อมกับบริการอื่นหนาแน่น
  • บริการภายใน (S3, DynamoDB, SNS, Redshift) ถูกเปิดให้คนนอกใช้ จนกลายเป็นธุรกิจ AWS

Walmart

  • ปรากฏเพียง จุดเดียว ที่ขอบเครือข่าย
  • แทบไม่มีเส้นเชื่อมไปยังกลุ่มอื่น
  • แข็งแกร่งด้านร้านค้าและซัพพลายเชน แต่ยังไม่เป็นแพลตฟอร์มที่คนอื่นมาต่อยอด

บทเรียนสำหรับ PCC

  1. เปิดความสามารถภายในให้คนนอกใช้ — สิ่งที่เราทำได้ดีอยู่แล้ว ถ้าเปิดเป็นบริการ/API ก็กลายเป็นรายได้ใหม่
  2. วัดความสำเร็จด้วยจำนวนคนที่มาเชื่อมต่อ ไม่ใช่แค่ยอดขายของเราเอง
  3. ขนาดธุรกิจไม่เท่ากับขนาดระบบนิเวศ — Walmart ใหญ่ แต่ในเครือข่ายนี้เป็นเพียงจุดเล็ก ๆ
ใครเป็นศูนย์กลางที่คนอื่นต้องมาเชื่อมต่อ คนนั้นได้เปรียบในยุคระบบนิเวศ
